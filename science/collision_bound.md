# A reduced-unitary bound from the program variance

One collision couples a data register to a fresh program specimen and then discards the specimen. Its first program moment determines the intended Hamiltonian. The difference between the second moment and the square of the first controls the channel error, uniformly over data inputs and their reference systems.

## Conditional expectation and variance

Let $`A`$ and $`E`$ be finite-dimensional data and environment spaces. Fix a state $`\sigma\in\mathsf D(E)`$ and a Hermitian operator $`H`$ on $`A\otimes E`$. Tensor factors are ordered with the data first. Define the program expectation of a joint operator $`Y`$ by

```math
\mathcal E_\sigma(Y)
=\mathrm{Tr}_E\!\left[
(I_A\otimes\sigma^{1/2})Y(I_A\otimes\sigma^{1/2})
\right].
```

Partial-trace cyclicity on the environment also gives

```math
\mathcal E_\sigma(Y)
=\mathrm{Tr}_E\!\left[(I_A\otimes\sigma)Y\right]
=\mathrm{Tr}_E\!\left[Y(I_A\otimes\sigma)\right].
```

This is a unital completely positive map. It is an analytical expectation, not an operation that the processor must evaluate. Define operators on $`A`$ and a scalar by

```math
h=\mathcal E_\sigma(H),\qquad
M=\mathcal E_\sigma(H^2),\qquad
v=\Vert M-h^2\Vert_\infty.
```

The operator $`M-h^2`$ is positive. To see its meaning, choose an auxiliary space $`F`$ and a purification $`|s\rangle\in E\otimes F`$ of $`\sigma`$. Let $`V:A\to A\otimes E\otimes F`$ be the isometry $`V|x\rangle=|x\rangle\otimes|s\rangle`$, and put $`\widehat H=H\otimes I_F`$. Then

```math
V^\dagger\widehat H V=h,\qquad
V^\dagger\widehat H^2V=M,
```

and

```math
M-h^2
=V^\dagger\widehat H(I-VV^\dagger)\widehat H V.
```

The variance therefore measures the coupling out of the subspace with the environment fixed in $`|s\rangle`$. The purification is used only in the proof; the physical source still supplies the mixed state $`\sigma`$.

## Lemma

For real $`\tau`$, define the physical collision channel and its intended unitary channel by

```math
\Phi_\tau(X)
=\mathrm{Tr}_E\!\left[
e^{-i\tau H}(X\otimes\sigma)e^{i\tau H}
\right],\qquad
\mathcal U_\tau(X)=e^{-i\tau h}Xe^{i\tau h}.
```

**Lemma.** For every real $`\tau`$,

```math
\Vert\Phi_\tau-\mathcal U_\tau\Vert_\diamond\le2\tau^2v.
```

The norm is unhalved. The statement has no small-time assumption, dimension factor, or omitted higher-order remainder.

## Proof

It suffices to take $`\tau\ge0`$; negative times follow by replacing $`H`$ with $`-H`$. Write $`u_s=e^{-ish}`$ and move the joint isometry into the data interaction picture:

```math
W_s=(u_s^\dagger\otimes I_{EF})e^{-is\widehat H}V.
```

The isometry $`W_s`$ obeys $`W_0=V`$ and $`\frac{d}{ds}W_s=-iK_sW_s`$, where

```math
K_s=(u_s^\dagger\otimes I_{EF})
(\widehat H-h\otimes I_{EF})
(u_s\otimes I_{EF}).
```

Each $`K_s`$ is Hermitian. Define $`C=\widehat H V-Vh`$. The relations $`V^\dagger C=0`$ and $`C^\dagger C=M-h^2`$ imply

```math
V^\dagger K_sV=0,\qquad
K_sV=(u_s^\dagger\otimes I_{EF})Cu_s,\qquad
\Vert K_sV\Vert_\infty=\sqrt v.
```

Let $`U_K(s,a)`$ denote the unitary propagator generated by $`K_s`$ between times $`a`$ and $`s`$. Variation of constants, with the fixed isometry $`V`$ as comparison, gives

```math
W_s-V=-i\int_0^s U_K(s,a)K_aV\,da.
```

Consequently,

```math
\Vert W_s-V\Vert_\infty\le s\sqrt v.
```

Now compress back to the fixed-environment subspace. The operator $`B_s=V^\dagger W_s`$ acts on $`A`$ and is a contraction. Since $`V^\dagger K_sV=0`$,

```math
B_\tau-I_A
=-i\int_0^\tau V^\dagger K_s(W_s-V)\,ds.
```

Hermiticity of $`K_s`$ gives $`\Vert V^\dagger K_s\Vert_\infty=\Vert K_sV\Vert_\infty=\sqrt v`$. It follows that

```math
\Vert B_\tau-I_A\Vert_\infty
\le\int_0^\tau sv\,ds
=\frac{\tau^2v}{2}.
```

Choose an orthonormal basis of $`E\otimes F`$ whose first vector is $`|s\rangle`$. In this basis the reduced interaction-picture channel has the decomposition

```math
\Psi_\tau(X)=B_\tau X B_\tau^\dagger+\mathcal L_\tau(X),
\qquad
\Psi_\tau(X)=u_\tau^\dagger\Phi_\tau(X)u_\tau,
```

where $`\mathcal L_\tau`$ is the completely positive contribution from the remaining environment basis vectors. Define its Stinespring operator $`F_\tau=(I-VV^\dagger)W_\tau`$. Then

```math
\mathcal L_\tau(X)=\mathrm{Tr}_{EF}(F_\tau X F_\tau^\dagger),\qquad
F_\tau^\dagger F_\tau=I_A-B_\tau^\dagger B_\tau.
```

For a completely positive map of this form, its diamond norm equals $`\Vert F_\tau^\dagger F_\tau\Vert_\infty`$. The upper bound follows by tracing its positive output on an arbitrary input-reference state, and equality is attained by an eigenvector of $`F_\tau^\dagger F_\tau`$ with maximal eigenvalue. Because $`(I-VV^\dagger)V=0`$,

```math
\Vert\mathcal L_\tau\Vert_\diamond
=\Vert F_\tau\Vert_\infty^2
\le\Vert W_\tau-V\Vert_\infty^2
\le\tau^2v.
```

The compressed contribution is also close to the identity channel. The identity

```math
B_\tau X B_\tau^\dagger-X
=(B_\tau-I_A)XB_\tau^\dagger
+X(B_\tau^\dagger-I_A)
```

and the trace-norm product inequality remain valid after tensoring every operator with the identity on a reference. Hence

```math
\Vert X\mapsto B_\tau X B_\tau^\dagger-X\Vert_\diamond
\le(\Vert B_\tau\Vert_\infty+1)\Vert B_\tau-I_A\Vert_\infty
\le\tau^2v.
```

Adding the leakage contribution gives $`\Vert\Psi_\tau-\mathrm{id}_A\Vert_\diamond\le2\tau^2v`$. Unitary postprocessing preserves diamond distance, so the same bound holds between $`\Phi_\tau`$ and $`\mathcal U_\tau`$.

This estimate retains a program-dependent variance instead of replacing it immediately by the norm of the full interaction.
